0. PROJECT SUMMARY AND RESEARCH QUESTIONS
--------------------------------------------------------------------------------
Goal: predict the mean fragment size X50 (m) of a bench blast from
  - blast geometry  : S/B (spacing/burden), H/B (bench height/burden),
                      B/D (burden/hole diameter), T/B (stemming/burden)
  - explosive       : Pf (powder factor, kg/m3)
  - rock properties : XB (in-situ block size, m), E (Young's modulus, GPa)
and compare RF, XGBoost, SVR, ANN (plus strong extra baselines) against the
empirical Kuznetsov/Kuz-Ram model and multivariate regression (MVR).

Research questions (write these into the paper introduction):
  RQ1  Which ML model predicts X50 most accurately, and is the difference
       statistically significant (not just a lucky 12-blast test split)?
  RQ2  Do ML models beat the empirical Kuznetsov equation and the MVR
       power-law of Hudaverdi et al.?
  RQ3  Which blast parameters have the greatest influence on X50
       (SHAP, permutation importance, PDP/ALE), and do the learned effects
       agree with blasting physics (e.g. higher Pf -> finer X50)?
  RQ4  How well do models generalise to an UNSEEN mine/quarry
       (leave-one-site-out) - the realistic deployment scenario?
  RQ5  How much uncertainty is attached to each prediction (intervals)?

Novelty vs. prior work (Kulatilake 2010, Shi 2012, Amoako 2022,
Gebretsadik 2024, Sci. Rep. 2025/2026):
  (a) largest public version of this database (110 blasts, 10 sites, incl.
      the 13 original validation blasts and Miami Mine data),
  (b) leakage-aware evaluation: duplicate-aware grouped CV + leave-one-site-out
      (prior papers report a single 12-blast split -> high-variance R2),
  (c) statistical model comparison (corrected resampled t-test),
  (d) physics-consistency check of the learned effects + conformal intervals,
  (e) a fully reproducible public Kaggle notebook.

Important observations to use in the paper:
  * All studies use (almost) the same Hudaverdi database but report ONE
    random split of ~12 blasts -> results are not comparable and have huge
    variance. We fix this with repeated/grouped CV (Phase 2).
  * The 12-13 "validation" blasts share mines with training blasts, several
    are near-duplicates (En13 == En4 inputs, Ru7 == Ru1 except T/B) -> the
    paper split over-estimates generalisation. We quantify this.
  * Kulatilake trained separate models per E-group; we test both "one global
    model" and "per-group model".

5. PHASE 2 - EVALUATION DESIGN  (define BEFORE training anything)
--------------------------------------------------------------------------------
Three complementary protocols; ALL models are run under ALL three.

 P1  "Paper split" (comparability with literature)
     train = 97 development blasts, test = 13 original validation blasts.
     Report R2, RMSE, MAE, MAPE, VAF, a20-index. Also report on the 12
     blasts that have Kuznetsov values (for Kuz-Ram comparison).
     Limitation: 13 points -> R2 CI is wide; show bootstrap 95% CI.

 P2  Repeated grouped K-fold CV (main result)
     10 repeats x 5 folds on all 110 blasts. GROUPS = identical-input
     clusters (rows with the same 7 inputs always fall in the same fold ->
     no memorisation leakage). Hyper-parameters tuned INSIDE each training
     fold (nested CV, inner 5-fold grouped, Optuna). 50 outer folds ->
     metric distribution -> mean +- std and statistical tests.

 P3  Leave-One-Site-Out (LOSO) CV (generalisation to a new mine)
     10 folds, each holds out one entire mine/quarry. This is the realistic
     "new site" scenario and is new in this literature. Expect lower R2 -
     this is a finding, not a failure. Report per-site RMSE.

 Metrics (compute on original scale, metres):
     R2, RMSE, MAE, MAPE(%), VAF(%) = (1 - var(y-p)/var(y))*100,
     a20-index = fraction of predictions within +-20% of measured value,
     plus pooled out-of-fold predicted-vs-measured plot.

 Leakage rules (write them in the paper):
     - Scaling, log transforms, feature selection, tuning: fitted on the
       training fold only (sklearn Pipelines guarantee this).
     - The test fold is touched exactly once.
     - No synthetic / augmented data ever enters a test fold.

6. PHASE 3 - BASELINES
--------------------------------------------------------------------------------
 B0  Mean predictor (sanity floor; R2 ~ 0).
 B1  Kuznetsov / Kuz-Ram empirical model.
     X50 = A (V/Q)^0.8 Q^(1/6) (E_rws/115)^(-19/20). It needs absolute
     burden, spacing, bench height, charge per hole and rock factor A that
     are NOT in the ratio database. Therefore:
       (a) use the published Kuznetsov predictions X50K of Kulatilake 2010
           Tables 4-5 for the 12 validation blasts (hard-code them; code in
           Appendix A), compare on those 12 blasts under P1;
       (b) state clearly in the paper that Kuz-Ram cannot be evaluated
           under P2/P3 because it needs absolute quantities.
 B2  MVR power law (Hudaverdi/Kulatilake):
       ln X50 = ln a + sum_i b_i ln(x_i)   (ordinary least squares)
     = linear regression on log-inputs and log-target. Fit (i) one global
     model, (ii) one per E-group like the original papers.
 B3  Ridge regression on standardised inputs (linear reference).

# Metrics and CV splitters (Phase 2)
from sklearn.metrics import r2_score, mean_squared_error, mean_absolute_error

def metrics(y_true, y_pred):
    y_true, y_pred = np.asarray(y_true), np.asarray(y_pred)
    return {"R2": r2_score(y_true, y_pred),
            "RMSE": mean_squared_error(y_true, y_pred) ** 0.5,
            "MAE": mean_absolute_error(y_true, y_pred),
            "MAPE": np.mean(np.abs((y_true - y_pred) / y_true)) * 100,
            "VAF": (1 - np.var(y_true - y_pred) / np.var(y_true)) * 100,
            "a20": np.mean(np.abs(y_pred / y_true - 1) <= 0.20)}

# groups = identical-input clusters -> duplicates never split across folds
DUP_GROUP = df.groupby(FEATURES, sort=False).ngroup().values

def repeated_group_kfold(groups, n_splits=5, n_repeats=10, seed=SEED):
    """Yields (train_idx, test_idx); each repeat shuffles groups into folds."""
    rng = np.random.RandomState(seed)
    uniq = np.unique(groups)
    for r in range(n_repeats):
        perm = rng.permutation(uniq)
        for k, fold_groups in enumerate(np.array_split(perm, n_splits)):
            test = np.isin(groups, fold_groups)
            yield r, k, np.where(~test)[0], np.where(test)[0]

def loso_splits(sites):
    # rep=0 for every fold (one pass over all sites); fold = held-out site name
    for s in np.unique(sites):
        test = sites == s
        yield 0, s, np.where(~test)[0], np.where(test)[0]

def paper_split():
    test = (df["paper_split"] == "validation").values
    yield "paper", 0, np.where(~test)[0], np.where(test)[0]

def logy(est):  # model on log(X50), predictions back in metres
    return TransformedTargetRegressor(regressor=est, func=np.log, inverse_func=np.exp)

def build(name, p):
    if name == "Mean":  return DummyRegressor()
    if name == "MVR":   return logy(make_pipeline(FunctionTransformer(np.log), LinearRegression()))
    if name == "Ridge": return make_pipeline(StandardScaler(), Ridge(alpha=p["alpha"]))
    if name == "RF":    return RandomForestRegressor(random_state=SEED, n_jobs=-1, **p)
    if name == "ET":    return ExtraTreesRegressor(random_state=SEED, n_jobs=-1, **p)
    if name == "XGB":   return XGBRegressor(random_state=SEED, n_jobs=4, verbosity=0, **p)
    if name == "LGBM":  return LGBMRegressor(random_state=SEED, verbose=-1, **p)
    if name == "CatB":  return CatBoostRegressor(random_seed=SEED, verbose=0, **p)
    if name == "SVR":   return logy(make_pipeline(StandardScaler(), SVR(**p)))
    if name == "GPR":
        k = ConstantKernel() * RBF(length_scale=np.ones(len(FEATURES))) + WhiteKernel()
        return logy(make_pipeline(StandardScaler(),
                    GaussianProcessRegressor(kernel=k, normalize_y=True,
                                             n_restarts_optimizer=5, random_state=SEED)))
    if name == "ANN":
        layers = tuple(p[f"n{i}"] for i in range(p["n_layers"]))
        return logy(make_pipeline(StandardScaler(),
                    MLPRegressor(hidden_layer_sizes=layers, activation=p["act"], alpha=p["alpha"],
                                 solver="lbfgs", max_iter=5000, random_state=SEED)))
    raise ValueError(name)

def space(name, t):
    if name == "Ridge": return {"alpha": t.suggest_float("alpha", 1e-3, 100, log=True)}
    if name in ("RF", "ET"):
        return {"n_estimators": t.suggest_int("n_estimators", 200, 800, step=100),
                "max_depth": t.suggest_int("max_depth", 2, 12),
                "min_samples_leaf": t.suggest_int("min_samples_leaf", 1, 8),
                "max_features": t.suggest_float("max_features", 0.3, 1.0)}
    if name == "XGB":
        return {"n_estimators": t.suggest_int("n_estimators", 100, 1000, step=50),
                "learning_rate": t.suggest_float("learning_rate", 0.01, 0.3, log=True),
                "max_depth": t.suggest_int("max_depth", 2, 6),
                "min_child_weight": t.suggest_float("min_child_weight", 1, 10),
                "subsample": t.suggest_float("subsample", 0.5, 1.0),
                "colsample_bytree": t.suggest_float("colsample_bytree", 0.5, 1.0),
                "reg_lambda": t.suggest_float("reg_lambda", 1e-3, 10, log=True),
                "reg_alpha": t.suggest_float("reg_alpha", 1e-3, 10, log=True)}
    if name == "LGBM":
        return {"n_estimators": t.suggest_int("n_estimators", 100, 1000, step=50),
                "learning_rate": t.suggest_float("learning_rate", 0.01, 0.3, log=True),
                "num_leaves": t.suggest_int("num_leaves", 4, 31),
                "min_child_samples": t.suggest_int("min_child_samples", 3, 20),
                "subsample": t.suggest_float("subsample", 0.5, 1.0), "subsample_freq": 1,
                "colsample_bytree": t.suggest_float("colsample_bytree", 0.5, 1.0),
                "reg_lambda": t.suggest_float("reg_lambda", 1e-3, 10, log=True)}
    if name == "CatB":
        return {"iterations": t.suggest_int("iterations", 300, 1500, step=100),
                "depth": t.suggest_int("depth", 2, 6),
                "learning_rate": t.suggest_float("learning_rate", 0.01, 0.3, log=True),
                "l2_leaf_reg": t.suggest_float("l2_leaf_reg", 1, 10, log=True)}
    if name == "SVR":
        return {"C": t.suggest_float("C", 0.1, 1000, log=True),
                "epsilon": t.suggest_float("epsilon", 1e-3, 0.3, log=True),
                "gamma": t.suggest_float("gamma", 1e-3, 10, log=True)}
    if name == "ANN":
        n = t.suggest_int("n_layers", 1, 3)
        p = {"n_layers": n, "act": t.suggest_categorical("act", ["relu", "tanh"]),
             "alpha": t.suggest_float("alpha", 1e-5, 1.0, log=True)}
        for i in range(n): p[f"n{i}"] = t.suggest_int(f"n{i}", 4, 64, log=True)
        return p
    return {}   # Mean, MVR, GPR: no tuning (GPR tunes its kernel by max. likelihood)

N_TRIALS = 40
def tune(name, Xtr, ytr, gtr):
    if name in ("Mean", "MVR", "GPR"): return {}
    cv = GroupKFold(n_splits=5)
    def obj(t):
        est = build(name, space(name, t))
        return -cross_val_score(est, Xtr, ytr, groups=gtr, cv=cv,
                                scoring="neg_root_mean_squared_error").mean()
    st = optuna.create_study(direction="minimize",
                             sampler=optuna.samplers.TPESampler(seed=SEED))
    st.optimize(obj, n_trials=N_TRIALS, show_progress_bar=False)
    p = space(name, optuna.trial.FixedTrial(st.best_params))
    return p

MODELS = ["Mean", "MVR", "Ridge", "RF", "ET", "XGB", "LGBM", "CatB", "SVR", "GPR", "ANN"]

# Run the benchmark under one protocol (nested tuning inside each outer fold)
def run_protocol(proto_name, splits, models=MODELS):
    rows, oof, params = [], [], []
    for rep, fold, tr, te in splits:
        for name in models:
            t0 = time.time()
            p = tune(name, X[tr], y[tr], DUP_GROUP[tr])
            est = build(name, p).fit(X[tr], y[tr])
            pred = est.predict(X[te])
            m = metrics(y[te], pred) if len(te) > 1 else {}
            rows.append({"protocol": proto_name, "rep": rep, "fold": fold, "model": name,
                         "n_test": len(te), "sec": time.time() - t0, **m})
            oof += [{"protocol": proto_name, "rep": rep, "model": name, "idx": i,
                     "y": yt, "pred": yp} for i, yt, yp in zip(te, y[te], pred)]
            params.append({"protocol": proto_name, "rep": rep, "fold": fold,
                           "model": name, "params": p})
        print(proto_name, rep, fold, "done")
    res, oof = pd.DataFrame(rows), pd.DataFrame(oof)
    res.to_csv(OUT / f"tables/folds_{proto_name}.csv", index=False)
    oof.to_csv(OUT / f"tables/oof_{proto_name}.csv", index=False)
    json.dump(params, open(OUT / f"tables/params_{proto_name}.json", "w"), default=str)
    return res, oof

# Statistics: corrected resampled t-test (Nadeau & Bengio 2003) on P2 folds
from statsmodels.stats.multitest import multipletests
def corrected_ttest(a, b, n_train, n_test):
    d = np.asarray(a) - np.asarray(b); J = len(d)
    var = np.var(d, ddof=1) * (1 / J + n_test / n_train)
    t = d.mean() / np.sqrt(var)
    return t, 2 * stats.t.sf(abs(t), J - 1)

# Uncertainty (Phase 7): split-conformal style 90% intervals from OOF residuals
def conformal_coverage(oof, model, alpha=0.10, n_iter=200):
    # Split-conformal check on out-of-fold residuals: calibrate the quantile on a
    # random half of the blasts, measure coverage on the other half, repeat.
    d = oof[(oof.model == model) & (oof.rep == oof.rep.iloc[0])]
    r = np.abs(d.y - d.pred).values
    rng = np.random.RandomState(SEED); cover, width = [], []
    for _ in range(n_iter):
        perm = rng.permutation(len(r)); cal, ev = perm[: len(r) // 2], perm[len(r) // 2:]
        n = len(cal); q = np.quantile(r[cal], min(1, np.ceil((n + 1) * (1 - alpha)) / n))
        cover.append(np.mean(r[ev] <= q)); width.append(2 * q)
    return round(np.mean(cover), 3), round(np.mean(width), 3)
